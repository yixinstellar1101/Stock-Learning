# 期权研习室 · 美股版

在线学习：[打开美股期权研习室](https://yixinstellar1101.github.io/Stock-Learning/)。

直接用 Chrome、Edge 或 Safari 打开 `index.html`。无需安装软件、启动服务或登录。课程、公式、图表和工具全部内嵌，外部原文链接需要联网。

包含 10 课中文课程、20 道测验、15 个官方资料入口、8 种头寸的到期盈亏图、BSM 定价与 Greeks、财报 IV 回落实验、模拟开平仓、5 个行业研究框架、正股持仓整理与学习手记。

建议从第 1 课开始，按四周路线学习。答对一课的两道测验后记录进度；可随时访问实验室和模拟交易。

## 已有正股

使用 `us-stock-holdings-template.csv`，或在网页的“正股持仓”页下载模板。每行一个代码：

| 字段 | 含义 |
| --- | --- |
| Ticker | 美股 / ETF 代码 |
| Quantity | 股数，允许小数，仅多头 |
| AverageCost | 每股平均成本，USD |
| LastPrice | 导出时每股价格，USD |
| Sector | 行业，自行填写 |
| Currency | 填 USD；其他币种分开分析 |

同代码先合并，成本用加权平均。支持 UTF-8 CSV、引号字段和字段内逗号；最多 500 行、1 MB。持仓仅存在本次页面内存，刷新清除，不会自动上传。股票权重不包括现金、期权、空头或负债。

后续分析还需明确：持有期限、资金用途、回撤承受能力、现金储备、卖股 / 接股意愿、账户权限和税务地区。券商文件可删去账号、住址与证件等身份字段后提供。

## 数据与模型口径

- 进度和手记保存在当前浏览器，可导出 JSON。换浏览器、移动 HTML、清理存储或隐私模式可能影响保存。导出不含持仓工作台数据。
- 行情、期权链、事件和成交全部虚构，不提供实时价格或当前行业评级。
- 到期图计算经济盈亏，标准乘数 100；不自动处理行权、税、股息、保证金或交割后股票风险。组合以同到期、腿数完整且正确交割为前提。
- 定价采用无股息欧式 BSM 模型；美股股票 / ETF 通常美式，模型不包含提前行权、离散股息、跳跃和流动性。
- 模拟只允许一个买入多头：限价达到 Ask 时按 Ask 成交，否则保留未成交状态；按 Bid 全数平仓。没有部分成交、排队、资金校验或实际行权。
- 本课程是教育与研究工具，不是针对个人的买卖建议或收益承诺。

## 来源与维护

检索日期：2026-10-26（Asia/Shanghai）。优先采用 OIC / OCC、Cboe、FINRA 和 SEC 官方资料。各课附来源；`SOURCES.md` 是中文导读清单，`research/sources.json` 记录访问状态。受限入口单独标注，不宣称已读登录内容或实时行情。

开发时运行 `npm install`、`npm run build`，生成独立 HTML。`npm test` 使用本机 Chrome 检查计算、开平仓、存储、CSV、资料筛选与移动布局。
